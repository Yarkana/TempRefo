# FPS Game Planning Example

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 게임 제목 | **O O O** |
| 장르 | FPS / Action |
| 개발 엔진 | Unreal Engine 5.4.4 |
| 플랫폼 | VR / PC(비추천) |
| 플레이 방식 | Single Player |
| 시점 | First Person |
| 예상 플레이 시간 | 30분~|

### 한 줄 소개
> 각양각색의 환경이 펼쳐지는 가상 군사훈련 시뮬레이션 속에서 목표를 완수하고 그 비밀을 파헤쳐가는 1인칭 FPS 게임입니다.

---

## 2. 게임 컨셉

훈련이 시작된다는 것을 알림과 동시에 플레이어는 최초 튜토리얼 맵을 빙자한 첫 챕터에서 간단한 조작법을 배우고 맵의 끝에 도달하여 기초훈련을 완수하는 것을 첫 목표로 삼습니다.

이후 본격적으로 수행되는 주요 훈련에서 오류가 발생하여 훈련에 문제가 생겼음을 인지하게 됩니다. 오류로 인해 환경이 시시각각 뒤바뀌는 시뮬레이션 속에서 훈련 종료 버튼이 오류로 사라지게 되고 플레이어는 무사히 탈출하는 것을 두번째 목표로 하게 됩니다.  

탈출을 향해가는 과정 속에서 최종적으로 플레이어는 오류가 발생하게 된 시뮬레이션의 심층부에 접근하게 되고 탈출을 위해 해당 지역 내에서 문제를 해결하는 것이 최종 목표가 됩니다.

### 핵심 키워드

- **Environment** : 변수를 부여하는 환경 요소
- **Combat** : 적과의 FPS 전투
- **Resource** : 제한된 자원
- **Planing** : 자원을 고려한 효율적인 계획
- **Escape?** : 훈련의 완수

---

## 3. 게임 목표

플레이어의 목표들은 다음과 같다.

1. 적을 처치하며 기초 훈련을 완수한다.
2. 주어진 각 목표들을 완수하여 주요 훈련을 완수한다.
3. 급변하는 환경 속에서 탈출 방법 또는 해결 방법을 찾는다.
4. 심층부의 문제를 해결한다.

---

## 4. Core Gameplay Loop

게임의 핵심 플레이 흐름은 다음과 같다.

```text
튜토리얼(정조준, 환경 요소와 소모품 사용, 적 발각 등의 요소)
  ↓
주어진 환경요소 인지
  ↓
적 배치 인지
  ↓
앞선 요소를 이용해 유리한 흐름을 구성하는 계획을 유도
  ↓
해당 구역의 적 처치
  ↓
탄약을 비롯한 자원 획득
  ↓
4~?개의 구역을 돌파
  ↓
적절한 시점에 챕터(맵과 환경) 변화
  ↓
새로운 자원과 환경요소
  ↓
심층부 도달
  ↓
문제해결&상황종료
```

플레이어는 게임이 종료될 때까지 **계획 → 전투 → 자원 획득 → 이동**의 과정을 반복한다.

## 6. 플레이어 기능

PC로 플레이 시 일부 기능은 자동 조정됨.

### 6.1 이동

플레이어는 FPS 방식으로 맵 내부를 자유롭게 이동할 수 있다.

주요 기능:
- 앞으로 / 뒤로 이동
- 좌 / 우 이동
- 마우스 시점 회전
- 점프
- 달리기

### 6.2 총기 조준
최초 튜토리얼에서 조준은 가늠쇠를 통한 정조준을 중심으로 보정을 받게 된다.
주어진 첫 주무장은 양손으로 총기를 잡지 않으면 극심한 반동 패널티를 부여받는다.
보조무장은 이러한 패널티가 존재하지 않기에 사격과 다른 행동과 병행할 수 있다.
난이도에 따라 조준에 얕은 보정을 부여받게 된다.

PC로 플레이 시 보정은 삭제된다.

### 6.3 조작 메뉴

양손에 주어진 조작 메뉴를 통해 다양한 행동에 접근할 수 있다.

주요 기능(왼손):
- 재장전(기본)
- 사용할 소모품 선택
- 왼손 보조무기 사용
- 일부 상호작용

주요 기능(오른손):
- 주무장 착용(기본)
- 보조무기 착용
- 무기 미착용(체력 제한 회복등의 양손을 요구하는 일부 상호작용)
- 일부 소모품 선택

### 6.4 조작 편의성
해당 요소는 입력없이 시행되는 요소다.
이동 도중 자세를 낮추면 슬라이딩하게 되어 빠른 이동이 가능하다.
적이 있는 도중엔 엄폐물을 향해 이동하는 경우에만 슬라이딩이 작동한다.
기본적으로 주변에 적이 없을 경우 달리기가 사용되어 빠른 정비와 이동을 가능케한다.
적이 있는 구역 진입 시 자동으로 걷기 상태로 전환되어 상황 인지를 돕는다.
탄창이 고갈되었을 경우 오른손으로 총기를 집어넣을시 자동으로 보조무기로 전환되는 등 일부 상황에선 필요한 조작을 자동으로 시행한다.


### 6.5 소모품 조작
붕대나 주사기 같은 일부 소모품의 경우엔 플레이어가 직접 컨트롤러를 이용해 팔에 상호작용해야한다.
일부 수류탄은 한손으로 사용가능하지만 대부분의 경우엔 양손 상호작용을 요구한다.


### 6.6 환경 상호작용
환경요소들은 경우에 따라 총기사격, 폭발물, 상호작용들을 요구한다.
환경요소에 따라 플레이어에게 다양하게 이득이 되는 상황을 부여받는다.

- 증원 차단
- 지형 변화
- 적 수 감소
- 우회
- 추가 자원
등등...
